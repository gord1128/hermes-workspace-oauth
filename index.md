# Hermes Workspace OAuth

A personal Google Workspace integration operated by [gord1128](https://github.com/gord1128). This is a private-use automation, not a public sign-up service or an official Google product.

## Purpose
The owner uses this integration to organize Gmail into category folders, preserve important mail, and run explicitly requested Workspace tasks. Gmail folder moves add a category label and remove the Inbox label; this automation does not permanently delete mail.

## Permissions
The current authorization requests Gmail read, send and modify; Calendar; Drive; Contacts read-only; Sheets; and Docs access. These permissions support the connected local Workspace tools. The scheduled mail organizer uses Gmail access; additional operations require the owner’s instructions.
